# Changelog

## 0.8.0 - 2026-09-03

### Control-plane consistency

- Promote `FluxaCoordinator` from catalog-refresh-only coordination to the authoritative low-frequency control-plane writer.
- Serialize configuration update/rollback mutations through the Durable Object instead of allowing edge PoPs to write the same KV keys independently.
- Store the active configuration revision, bounded rollback history and administrator audit log in SQLite-backed Durable Object storage; pre-v0.8 KV history/audit are imported once during control-state bootstrap.
- Keep Workers KV as the edge-readable configuration cache so proxy/subscription requests remain stateless and globally distributed.
- Add monotonic configuration revisions and HTTP `ETag` / `If-Match` optimistic concurrency so stale administrator tabs cannot overwrite a newer configuration.
- Add stale catalog commit protection: catalog discovery may run concurrently with config edits, but the coordinator rechecks the active config inside the mutation queue immediately before writing the catalog KV key and discards stale refresh results.
- Preserve data-plane separation: VLESS/Trojan traffic never traverses the Durable Object.

### Release verification

- Expand regression coverage from 44 to 52 tests for control-state revisioning, rollback/history behavior, ETag parsing, coordinator client behavior and admin `If-Match` wiring.
- Add Wrangler deployment dry-runs to GitHub CI and tag Release Gate so Cloudflare configuration/bundling is checked in addition to TypeScript tests.
- Continue to treat a real Cloudflare deployment and real-client connection test as the final verification stage.


## 0.7.0 - 2026-09-03

- Add a SQLite-backed `FluxaCoordinator` Durable Object for global node-catalog refresh coordination across Worker PoPs.
- Keep proxy data-plane traffic stateless; only the shared catalog refresh enters the coordinator.
- Stop persisting request-specific Worker/custom-domain hostnames in the shared catalog.
- Exclude legacy `worker`-origin catalog candidates immediately and purge them on refresh.
- Add graceful Worker-host-only subscription fallback when a required catalog rebuild fails.
- Add coordinator diagnostics/capability flags and release-gate validation for the Durable Object binding/export.
- Expand automated regression coverage from 41 to 44 tests.

## 0.6.0 - 2026-09-03

### Reliability and correctness

- Coalesce concurrent catalog refreshes per Worker isolate with single-flight execution and add a short failed-refresh retry cooldown.
- Add a catalog configuration fingerprint so catalogs generated by old configuration are rebuilt before subscription use.
- Add a 15-second proxy-handshake deadline and 4 MiB inbound WebSocket-frame ceiling.
- Add timeout plus stale-last-known-good fallback for the Cloudflare official IP range API.
- Replace textual IPv6 private-range checks with numeric CIDR validation and fix overly broad IPv4 `192.0.0.0/16` blocking.

### Maintenance

- Pin direct TypeScript/Wrangler development versions.
- Raise supported local Node.js baseline to 22+ and test Node 22/24 in CI.
- Add Dependabot for npm/GitHub Actions and weekly CodeQL analysis.
- Release gate verifies runtime/package version consistency and exact direct toolchain versions.
- Document Workers KV eventual consistency instead of promising instant global propagation.

### Tests

- Expanded automated regression suite from 38 to 41 tests, including single-flight behavior, catalog fingerprint invalidation and expanded IPv4/IPv6 public-target validation.

## 0.5.0 - 2026-09-03

### Security boundaries

- Pin HTTP CONNECT upstream destinations to a validated public A/AAAA address to prevent DNS-rebinding/resolver-disagreement access to private networks.
- Use constant-time comparison for VLESS UUID and Trojan password-hash authentication.
- Reserve management/subscription routes so proxy paths cannot shadow `/api`, `/sub`, `/admin`, or `/health`, and prevent VLESS/Trojan path collisions.
- Fail malformed percent-encoded subscription paths closed instead of throwing URI decoding errors.
- Bound administrator JSON request bodies and require `application/json`.
- Replace unrestricted inline-script CSP with a per-response nonce on the admin page.

### Tests

- Expanded automated regression suite from 30 to 38 tests, including DNS-rebinding rejection, reserved-route validation, bounded JSON reads, malformed URL decoding, CSP nonce generation and wrong protocol credentials.

## 0.4.0 - 2026-09-02

### Reliability

- Serialized WebSocket ingress processing to prevent frame-order races during protocol handshake and tunnel establishment.
- Added bounded direct TCP socket-open and HTTP CONNECT handshake timeouts with cleanup.
- Added synchronous `connect()` failure handling before selective upstream fallback.
- Extended Cloudflare destination detection to official IPv6 CIDRs and DoH AAAA answers in addition to IPv4/A.

### Recovery and operations

- Added bounded configuration history with eight non-secret snapshots.
- Added authenticated `/api/config/history` and `/api/config/rollback`.
- Added one-click rollback UI with automatic pre-rollback snapshot.
- Added read-only `npm run smoke` post-deployment checker.
- Reduced maximum configured external sources to 16 and added four-way bounded source fetch concurrency to stay within Workers Free request/connection limits.

### Tests

- Expanded automated regression suite from 24 to 30 tests, including queue ordering, timeout behavior, IPv6 CIDR matching and config-history recovery.

## 0.3.0 - 2026-09-02

### Added

- Plain URI subscription output.
- Loon VLESS/Trojan WebSocket subscription generator.
- Surge Trojan WebSocket subscription generator with documented-compatibility-only policy.
- Mihomo, v2rayN, v2rayNG and Shadowrocket format aliases.
- User-Agent based automatic subscription format selection.
- Subscription `HEAD`, ETag/conditional GET and version/format metadata headers.
- Public `/api/capabilities` endpoint.
- Authenticated `/api/diagnostics` endpoint.
- Authenticated bounded KV audit log for administrative changes and manual catalog refreshes.
- Release-time hard-coded production-secret scan.

### Security

- Third-party source redirects are followed manually and every redirect target is revalidated as a public HTTPS destination.
- Administrator audit events sanitize control characters and do not contain credentials or client traffic.
- Expanded secret-separation validation.

### Tests

- Expanded automated regression suite from 16 to 24 tests.
